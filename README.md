# Snipingzoo

Team site for Snipingzoo, trickshotting and sniping since 2011. It's a single page (`index.html`) built as a game-style lobby menu:

- Title screen ("Sniping Zoo" lockup + Press Any Key); press **R** on the menu to replay it
- Main menu: Roster, Unleash the Beasts, Feed the Beasts, About, Branding Kit, Store, Socials
- Live lobby: visitors enter a gamertag and show up in the party list (works when hosted as a claude.ai artifact; elsewhere it needs a realtime backend)
- Branding kit download popup, gamertag profanity filter

## Editing

All text, names, links, episodes and options live in the `CONFIG` block near the bottom of `index.html`.
Colours are at the top under `:root`.

## Files

- `index.html` — the whole site
- `sz-lockup-logo.png` — gold SZ logo used in the title-screen lockup
- `fonts/` — licensed webfonts (Bank Gothic Medium, ITC Conduit Regular & Bold)
